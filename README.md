# kaleidoscope

에이전트가 작업용 UI와 앱을 만들고 고쳐 올리는 데스크톱 쉘입니다.
로컬 파일 편집기, Shay 대사 뷰어, 코르크시트처럼 에이전트가 만든 작은 앱을 작업 맥락별 데스크톱에 펼쳐 두고, 상태를 유지한 채 전환하며 일합니다.

## 현재 스펙

| 축 | 내용 |
|---|---|
| 제품 | 에이전트가 작업용 UI와 앱을 생성, 수정해 올리는 데스크톱 쉘. 뷰어는 앱 유형 가운데 하나 |
| 작업 환경 | 여러 데스크톱에 자료와 도구를 펼쳐 두고, 상태를 유지하며 전환 |
| 데이터 연결 | 이종 데이터 소스를 연결해 조회, 비교, 편집하고, 소스가 지원하는 CRUD와 기능 실행 |
| 사용 방식 | 사용자가 UI를 직접 조작하며, 에이전트에게 도구 생성, 변경, 작업 수행을 요청 |
| 기본 구성 | 로컬 앱 + 로컬 서버 + 오케스트레이션 서버 |
| 공유 | 오케스트레이션 서버를 통해 워크스페이스 공유 |

## 상태

설계 단계입니다. 역할 분담, 공유 범위, 생성과 실행 방식은 아직 정하지 않았고 기술 스택도 미정입니다.
설계 결정과 진행 기록의 정본은 atom `project > kaleidoscope`에 있습니다.
