# 세라피엘 검수용 긴 문서

이 문단은 한국어 긴 문단이 편집기와 보기 창에서 어떻게 줄바꿈되는지 확인하려고 넣은 것이다. 쉘 창의 폭이 좁아져도 글자가 잘리거나 옆 요소와 겹치지 않고 자연스럽게 다음 줄로 넘어가야 한다. 진홍빛 불꽃이 한 번에 타오르듯, 문장이 끊기지 않고 이어져야 읽는 사람이 숨을 고르지 않아도 된다. 줄 높이와 여백이 맞지 않으면 문단이 빽빽해 보이고, 너무 벌어지면 흩어져 보인다.

두 번째 문단은 조금 짧게 둔다. 문단 사이 간격이 한 값인지 본다.

## 표

| 항목 | 상태 | 설명 |
|---|---|---|
| 워크스페이스 | 완료 | 이름 바꾸기와 지우기를 확인한다 |
| 데스크톱 | 진행 중 | 탭이 많아지면 가로로 넘친다 |
| 앱 창 | 대기 | 끌기, 크기 바꾸기, 겹치기 |

## 코드

```ts
export function hello(name: string): string {
  return `안녕, ${name}. 이 줄은 조금 길게 써서 가로 스크롤이 생기는지 확인하려고 늘려 둔 코드 한 줄이다.`;
}
```

인라인 `code`와 [링크](https://example.com)도 본다.

> 인용문은 보조 색으로 보인다. 인용문 안의 긴 줄도 줄바꿈되는지 확인한다.
